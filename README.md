This game was developed as part of a master's thesis. All in-game purchases are simulated and do not require real money.

# ProtoStar

**ProtoStar** is a 2D top-down space shooter prototype developed in **Godot Engine 4** as part of a Master's thesis at the University of Maribor.

The project demonstrates the implementation of **digital goods** and **ethical monetization systems** in a computer game, including virtual currencies, boosters, loot boxes, battle passes, and an in-game economy.

---

## About the Project

The primary goal of ProtoStar is not to create a commercial game but to serve as a research prototype for evaluating modern monetization mechanics and best practices in game design.

The implemented systems focus on balancing:
- Player progression
- Fair monetization
- Long-term engagement
- Ethical game design

---

## Features

-  2D top-down space shooter
- Dual-currency economy
  - Gold (standard currency)
  - Crystals (premium currency)
- In-game shop
- Booster system
- Loot box system
- Battle Pass system
- Mission system
- Energy system
- Collectible ship skins
- Player progression and experience system

---

## Master's Thesis

This repository accompanies the Master's thesis:

> **Best Practices in Designing and Implementing Digital Goods for Computer Games**

The thesis investigates:
- Digital goods
- Game monetization
- Virtual economies
- Player behaviour
- Ethical monetization
- Best implementation practices

## Running the Project

1. Install **Godot Engine 4.x**
2. Clone this repository:

```bash
git clone https://github.com/Adam-192/Protostar.git
```

3. Open the project using Godot.
4. Run the `scene_select_language.tscn` scene.
